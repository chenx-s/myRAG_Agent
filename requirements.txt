# ================================================================
# 已知兼容性坑（代码里已经绕过，这里记录备查）
#
# 1) ragas 0.4.x 会 `from langchain_community.chat_models.vertexai import ChatVertexAI`，
#    而 langchain-community 0.4.x 已删除该模块，导致 `import ragas` 直接报
#    ModuleNotFoundError。eval_ragas.py 里注入了一个占位模块来绕过，
#    不需要为此降级任何依赖。
#
# 2) 环境变量不能叫 MILVUS_URI。pymilvus 3.x 在 import 阶段就会读取它并按
#    http[s]:// 解析，本地文件路径会让 `import pymilvus` 直接抛异常。
#    本项目用的是 RAG_MILVUS_URI。
#
# 3) 不需要 chromadb / faiss-cpu —— 那是上一版（Chroma/FAISS）的依赖，
#    本版已全部换到 Milvus，这两个可以卸载。
# ================================================================
